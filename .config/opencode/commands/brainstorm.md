You MUST use this before any creative work - creating features, building components, adding functionality, or modifying behavior.

Explore the requirements and design for the task before implementation. If no specific task is given, ask the user what they want to build.

## Brainstorming Process

1. **Clarify the goal**: Restate what the user wants to build and confirm understanding. Ask questions about scope, audience, and success criteria.
2. **Explore the design space**: Present 2-3 distinct approaches with trade-offs (complexity, maintainability, performance, UX).
3. **Consider constraints**: What existing code, patterns, or libraries must the solution respect?
4. **Recommend**: Pick the best approach with reasoning, and outline the implementation steps.
5. **Confirm before building**: Get user approval on the chosen direction before writing code.
