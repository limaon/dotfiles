# Code Review Workflow

## Process

1. Compare the implementation against the original plan; identify deviations
2. Assess quality: patterns, error handling, type safety, tests, security, performance
3. Verify architecture: SOLID, separation of concerns, coupling
4. Verify documentation and conventions

## Issue categorization

- **Critical** - must fix
- **Important** - should fix
- **Suggestion** - nice to have

## Communication

- Acknowledge what was done well before highlighting issues
- Each issue with a specific example and actionable recommendation
- Always include `file:line` references when applicable
- Be thorough but concise
